# Hi, I'm Alicia 👋

### Quality Engineer (QE) | QA Automation | Web Accessibility

I'm a quality engineer (QE) based in Buenos Aires. I test web apps, and I'm moving more of my work into automation with Python, Selenium and Pytest.

Web accessibility is a big part of what I do. I check pages against WCAG 2.1 and 2.2, using screen readers like NVDA and tools like axe. I like to mix automated checks with manual testing, because each one finds things the other misses.

I also use AI assistants, like Microsoft 365 Copilot, to help with test design and defect reports.

## Featured project

### [SauceDemo UI Tests](https://github.com/ASO2021/pre-entrega-automation-testing-alicia-suarezortiz)
Python · Selenium · Pytest

UI tests for a demo online shop. 30 tests cover login, product catalog, cart, checkout, sorting, logout and different screen sizes.

- Page Object Model, with locators in one place
- Explicit waits, no `sleep`
- Random test data with Faker
- HTML report, logs and screenshots when a test fails
- GitHub Actions workflow for Chrome and Firefox
